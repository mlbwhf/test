A scaled-agile planning tool in the iObeya space: where's the opening?

An opportunity assessment for a visual planning and reporting product that connects to Jira and Azure DevOps by default, supports SAFe and the other scaling models, and also runs on its own.

Bottom line

The opportunity is real, but a straight iObeya clone is not the best way in. The opening is a framework-neutral planning and insight layer that treats Jira, Azure DevOps (and later GitHub) as equal sources. It should model any operating model (SAFe, LeSS, Scrum@Scale, Nexus, Flight Levels or a homegrown hybrid) as configuration, not code, and put reporting first instead of adding it later.

The best first customers are companies with 300 to 5,000 people in delivery that find Jira Align too heavy or expensive, run mixed Jira and ADO estates, or are being pushed off Jira Data Center before it ends in 2029.

Why now: five market shifts

Atlassian

Jira Data Center is ending

Atlassian announced in September 2025 that Data Center products end on 28 March 2029. Regulated, defence and public-sector buyers who can't move to Atlassian Cloud need planning tools they can host themselves. A self-hostable or sovereign-cloud option is a real way to stand out here.

Atlassian

Jira Align is expensive and is being bundled

Third-party pricing trackers list the Strategy Collection (Jira Align, Focus and Talent) at about $77,400 a year for its smallest tier. Reviewers mention six-month rollouts, consultants needed to keep it in use, and Jira data that doesn't map cleanly. Atlassian's new strategy products are Jira-first and cloud-only, which leaves ADO shops out.

Microsoft

Azure DevOps is in maintenance mode

New Microsoft investment is going into GitHub, while Azure Boards gets mostly small fixes. The typical 2026 setup is code on GitHub with planning still in ADO Boards. A planning layer that spans ADO, Jira and GitHub Issues becomes the neutral place to plan.

Frameworks

Buyers are moving from SAFe-only to hybrid models

SAFe's survey share has roughly halved. Scaled Agile's own 2025 report says customers adapt SAFe heavily and ask for simplification. A tool that hard-codes SAFe is aiming at a shrinking target. A tool that lets each company define its own model fits where the market is going.

Whiteboards

Miro and Mural run PI planning, but their sync is shallow

Miro's Planner needs the Enterprise plan for ADO sync. Users report that story points and assignees don't sync back. Whiteboards made remote PI planning normal, but they give programme leaders no planning data model and no reporting.

Competitive landscape

The market splits into four groups: visual boards (iObeya, Miro, Mural), PI-planning add-ons (Kendis, Easy Agile), heavy portfolio suites (Jira Align, Planview, Digital.ai, IBM Targetprocess) and the platform vendors' own tools (Atlassian Focus). No player combines all three of: equal Jira/ADO support, any framework, and strong analytics.

White space: what to build that others don't

Core differentiator

Operating-model builder

Frameworks are configuration: hierarchy levels, names for each level (Epic, Capability, Feature), cadences, ceremonies, roles, board layouts and default metrics. Ship ready-made templates and let coaches fork and mix them.

Core differentiator

One planning model across Jira, ADO and GitHub

A shared data model with per-team field mapping, so one train can include Jira teams and ADO teams. Dependencies can cross tools. Changes on the board write back to each source.

Core differentiator

Reporting first

Drag-and-drop dashboard builder over a curated metrics catalogue: the six flow metrics, PI predictability, objective achievement, dependency health, ROAM risk burn-down, capacity versus load, and DORA. Scheduled PDF and Slack/Teams digests, plus Power BI and Tableau connectors.

Strong supporting feature

Standalone mode

A native backlog lets business, hardware or non-software teams plan without Jira or ADO. They can connect later without migrating. This also makes free trials possible with no setup.

Strong supporting feature

AI facilitation

Spots hidden dependencies and overloaded teams, drafts PI objectives from features, summarises ROAM risks, checks readiness before an event, and writes the executive narrative for each dashboard.

Strong supporting feature

Hosting where the customer needs it

Multi-tenant SaaS, a single-tenant EU or US region, and a self-hosted container build. This targets buyers affected by Data Center end of life and EU data-sovereignty rules.

Suggested phased roadmap

Months 0–6 · MVP

Win PI planning for mixed Jira/ADO trains

  • Two-way connectors for Jira Cloud and Azure DevOps Services, with field mapping
  • Program board, team planning boards, dependency lines, ROAM risk board, PI objectives with business value
  • Templates: SAFe Essential and a generic "team of teams"
  • Ten standard reports, including predictability, load versus capacity and dependency health
Months 6–12

Flexibility and insight

  • Operating-model builder, plus LeSS, Scrum@Scale, Nexus and Flight Levels templates
  • Dashboard builder, scheduled digests, BI connectors
  • Jira Data Center, Azure DevOps Server and GitHub Issues connectors; standalone backlog
  • SOC 2 Type II
Months 12–24

Portfolio and AI

  • Lean portfolio: epics, guardrails, participatory budgeting, OKRs
  • AI facilitator and narrative reporting
  • Self-hosted edition, ISO 27001, sovereign-region hosting

Positioning and pricing

Positioning: "Plan at scale your way, across Jira and Azure DevOps, with reporting leadership actually uses." Sell on time to first PI (days, not months) and on fitting any model.

  • Price: between Kendis and Jira Align. For example, $12–20 per planner per month, with free view-only and team-member access. Charging only for active planners was one of Jira Align's better ideas.
  • Channels: Atlassian Marketplace and Visual Studio Marketplace listings for discovery. SAFe and agile consultancies as resellers, since they run the PI events. Atlassian partners running Data Center to Cloud migrations.
  • Way in: one Agile Release Train, one PI, run with a coach. Expand train by train, then to the portfolio.

Next steps to validate

  1. Interview 15–20 Release Train Engineers, LACE leads and PMO heads, split across Jira-only, ADO-only and mixed estates. Ask what they use today, what they pay, and what their last PI planning event cost in prep time.
  2. Get real quotes for iObeya, Jira Align and Kendis so price positioning is based on facts, not aggregator figures.
  3. Build a sync prototype: one board with a Jira project and an ADO project, with one dependency across them, writing back to both.
  4. Run a paid pilot with one consultancy at a real PI event before building the dashboard builder.
  5. Contact Scaled Agile about their partner program before using SAFe branding.
