## 5) Arabic (RTL) — must-do
- Page **language = Arabic** so the theme loads `rtl.css` (flips the whole layout).
- The hero/band/enroll **Custom-HTML blocks** are hardcoded LTR — on the Arabic versions wrap each block's outer `<div>` with `dir="rtl"` and change `text-align:left` → `text-align:right` (and swap any left/right padding). The `[aa_cohorts]` schedule and the form flip automatically with the page locale; only the hand-built HTML blocks need `dir="rtl"`.
- Keep Latin tokens (SAFe®, Apple/Google Pay, USD, agile-agilist.com, prices) LTR inside the RTL text — browsers handle this, but verify numbers/brand names render correctly.
- **Native proof required** before publish.
