Compose

“Mark as posted” records the text in this account's ledger so future drafts are checked against it. Actual publishing is copy-paste (or your own workflow).

Ledger

    Settings

    Stored only in this browser's localStorage and sent only to api.groq.com. Get a key at console.groq.com. Don't use this on a shared machine.

    Fields per account: id, name, platform, focus, audience, voice, hashtags[], topics[] (keywords for mix-up detection).

    Edit template

    Import already-published posts

    Paste posts published before you started using this tool, so the duplicate/mix-up guard knows about them. They are recorded into the ledger of the currently active account.
