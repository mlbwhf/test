# Trainyard for Azure DevOps

Scaled agile planning inside Azure Boards. The hub opens your Trainyard server in the project: the program board and PI planning boards, the portfolio Kanban, value stream identification and mapping (with wait time, active time and %C&A calculated from work item history), the SAFe canvases and the dashboards.

Trainyard is open source (Apache-2.0). Run your own server or use https://agileagilist.com, then connect it to Azure DevOps under **Jira & Azure DevOps** for two-way sync.
