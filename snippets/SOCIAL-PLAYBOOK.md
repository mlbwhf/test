# Agile Agilist — Social Media Optimization Playbook

Scope: profile-level optimization + content system for LinkedIn, YouTube,
Instagram, Facebook, TikTok (the five in the site footer). Written against
the actual business: Scaled Agile Gold Partner, SPCT-led SAFe certification,
AI-Native training, the "Operating Model in the Age of AI" framework (5
layers), assessments, and Stripe-first course enrollment.

Golden rules that apply to every platform:
1. **One name, one handle, one logo, one teal.** Same display name
   ("Agile Agilist"), same logo avatar, same #127E88/#0B2E35 brand colors,
   same one-line positioning everywhere. Consistency is a trust signal for
   both humans and search/answer engines.
2. **Every profile links to the site with UTM tags** so you can see which
   platform actually sends enrollments:
   `https://agile-agilist.com/?utm_source=linkedin&utm_medium=social&utm_campaign=profile`
   (change `utm_source` per platform).
3. **The positioning line** (reuse everywhere, adapt length):
   > SPCT-led SAFe certification & enterprise transformation. Scaled Agile
   > Gold Partner · 4.9/5 · 2,500+ leaders trained. Home of the Operating
   > Model in the Age of AI.
4. **CTA priority:** 1) upcoming course cohort, 2) free assessment
   (Agile Maturity / Career Selector — best lead magnets you own),
   3) Book Consult.

## 1. LinkedIn (your #1 platform — B2B training sells here)

**Company page checklist**
- [ ] Banner: teal-dark hero with "Operating Model in the Age of AI" + Gold
      Partner badge + 4.9/5 · 2,500+ trained (match the site's utility strip).
- [ ] Tagline (220 chars): the positioning line above.
- [ ] About section: first 2 lines must carry the keywords people search —
      "SAFe certification", "SPC", "Agile training", "enterprise agility",
      "AI-Native operating model" — LinkedIn About is indexed by Google.
- [ ] Custom button: **"Sign up"** → the next open cohort page (not the
      homepage) with `utm_source=linkedin`.
- [ ] Add all courses as **Products/Services** entries (SPC, ASPC, RTE, LPM,
      APM, Leading SAFe, AI-Native) — each links to its course page.
- [ ] Turn on the **Lead Gen form** on the page if you run any LinkedIn ads.

**Content system (3 posts/week is enough if consistent)**
- Pillar A — *Proof*: one testimonial card per week (you have role-based
  reviews in `reviews.md`); alternate with cohort-completion shoutouts.
- Pillar B — *Framework*: one carousel per week explaining ONE layer of the
  5-layer Operating Model (5 carousels, then remix — this is your unique IP,
  nobody else can post it).
- Pillar C — *Cohort CTA*: one post per week: next course date + 2–3 seat
  urgency + Stripe enroll link. Plain, factual, every week.
- Founder profile (Mark) should reshare each post with one personal sentence
  — founder reach on LinkedIn is 5–10× the company page's.

## 2. YouTube (SEO asset — training questions are searched here)

- [ ] Channel name "Agile Agilist", handle to match, same banner as LinkedIn.
- [ ] Channel description: positioning line + link block (site, next cohort,
      free assessment) with UTMs.
- [ ] Video strategy: **answer real exam/cert questions** — "Is the SPC exam
      hard?", "SAFe SPC vs ASPC — which one?", "What is an AI-Native

- [ ] Every description: course link with `utm_source=youtube` + the free
      assessment link.
- [ ] Cut each video into 2–3 Shorts (same content, vertical) — Shorts feed
      the algorithm and cost nothing extra.

1. **Organization schema `sameAs`** — add the 5 social URLs to a site-wide
   Organization JSON-LD block. This is how Google/LLMs learn these accounts
   are officially yours (Knowledge Panel + brand answers). I can generate
   this snippet — I just need the 5 exact profile URLs.
2. **UTM discipline** — all social → site links carry
   `utm_source/<platform>`; then GA4 (or Jetpack Stats) shows which platform
   actually sells seats. Decisions follow data, not vibes.
3. **Footer icons already exist** — verify each footer icon points to the
   real profile (not a placeholder) — I can check the footer HTML if you
   paste the URLs.
4. **Course pages ↔ social proof loop**: the testimonial cards on course
   pages should match what's posted on LinkedIn — same quotes, same names.
   Recognition across touchpoints is what makes proof believable.
