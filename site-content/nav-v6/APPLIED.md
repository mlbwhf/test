## What v6 changes over v5

| Area | v5 | v6 |
|---|---|---|
| Auto lists per section | capped at 10 (Enterprise 13, Technical 10+, Dark Side 21 truncated) | uncapped; panes scroll |
| Latest reports | 6 newest | 30 newest, excluding pages already in the menu |
| Duplicates | real menu children were listed again by the auto list | de-duplicated |
| Redirect stubs | could be listed (1111 lives under /indexes/ai-dark-side-statistics/) | 866 and 1111 never listed |
| Phone drawer | every level-3 list forced open (about 150 links in one scroll) | sections collapsed, with a 52×44 +/− button showing the page count |
| Phone tap on Indexes/Reports text | first tap swallowed (`hover:none` check) | navigates |
| Tablet (touch, >768px) | tap on a section row navigated immediately; emulated mouseleave closed the panel | first tap shows the pane, second tap opens the hub; closes on a tap outside |
| Plain dropdowns (About) | anchored at the left edge of the nav | open under their own item |
| Search | sidebar only | search box in the desktop utility strip and the phone drawer |
| Site map | footer only | utility strip, drawer and About menu |
| Utility strip | `div role=navigation` | `<nav aria-label="Utility">` |

## LLM and crawler notes

- Every level-2 and level-3 link is server-rendered in the header HTML; JavaScript only adds
  pane chrome and the accordion buttons. A crawler without JS sees the full site tree on every
  page, grouped by section, with descriptive page titles as anchor text.
- /site-map/ (4231) uses AIOSEO's HTML sitemap and links /sitemap.xml and /llms.txt.
- llms.txt is generated by AIOSEO (UI-managed; do not write AIOSEO options via MCP).
