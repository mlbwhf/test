Fact check

Numbers to stop quoting

Widely repeatedWhat the evidence supports
“Meta released Llama 5, a 600-billion-parameter open model with a 5-million-token context window, in April 2026.”No Llama 5 has been released: Meta's newest Llama models are still Llama 4 (April 2025). Meta's April 2026 release was Muse Spark, a closed model; its open-weight successor, Muse Spark Open (October 2026), has 816 billion total and 42 billion active parameters and a 1-million-token context window. · detail
“Llama (or DeepSeek, or Qwen) is open-source.”These are open-weight models: the weights can be downloaded under licence terms, but the training data and full training code are not released. Only models that also release those, such as OLMo, Pythia and Apertus, meet the Open Source Initiative's Open Source AI Definition 1.0 (October 2024).
“A 1-trillion-parameter model costs ten times as much to run as a 100-billion-parameter model.”Not for mixture-of-experts models, which run only their active parameters per token. Kimi K3.1 Pro has 2,780 billion parameters but activates 104 billion per token.
Definitions

Terms used in this index

Large language model
A neural network, almost always a transformer, trained on very large text corpora to predict the next token, then usually tuned to follow instructions.
Total vs active parameters
Total parameters are all the weights a model holds (and so the memory needed to serve it). In a mixture-of-experts model only a subset, the active parameters, runs for each token, which sets the compute cost per token.
Reasoning model
A model trained to generate intermediate reasoning steps before its final answer, spending more inference-time compute on harder problems. A hybrid model lets that reasoning be switched off or capped.
Open-weight vs open-source
Open-weight: the trained weights are downloadable under a licence. Open-source AI (OSI definition, 2024): weights plus training code and sufficient information about the training data, under terms that allow use, study, modification and sharing.
State-space / linear-attention hybrid
An architecture that replaces most full-attention layers with layers whose cost grows linearly with sequence length (Mamba, Gated DeltaNet, Kimi Delta Attention), keeping a few attention layers for recall.
Diffusion language model
A model that generates by iteratively refining a full draft of masked tokens in parallel, rather than writing one token after another.
Context window
The maximum number of tokens a model can take in one request, prompt and conversation history included.
Frontier model
A model at or near the leading edge of capability and training compute at its release; this index uses Epoch AI's top-5-by-compute flag, a 10²⁵ FLOP estimate, or a top-tier closed flagship of a lab with such a run on record.

Frequently asked

How are large language models categorized?

Report AI classifies LLMs on eight dimensions: architecture (dense, mixture-of-experts, hybrid, diffusion), training stage and reasoning, openness (closed, open-weight, open-source), modality, size and deployment, specialisation, training-compute class and origin. Its November 2026 table places 93 notable models on each.

What is the difference between an open-weight and an open-source LLM?

An open-weight model's trained weights can be downloaded under a licence, but its training data and full code usually are not released. An open-source model under the Open Source Initiative's 2024 definition also releases the training code and enough information about the data to rebuild it; OLMo, Pythia and Apertus qualify, Llama, DeepSeek and Qwen do not.

What is a mixture-of-experts model?

A mixture-of-experts model splits its feed-forward layers into many experts and routes each token to a few of them, so only a fraction of its parameters runs per token. In Report AI's table, 27 of 43 open-weight models released in 2025–26 use the design; Kimi K3.1 Pro has 2,780 billion total and 104 billion active parameters.

How many LLMs are reasoning models?

In Report AI's table, 43 of 64 models released in 2025–26 (67.2%) have a reasoning mode, against 1 of 27 released in 2023–24. On Artificial Analysis's index in November 2026, 108 of 113 indexed model variants were reasoning variants.

Which LLMs were trained with the most compute?

On Epoch AI's estimates (database downloaded 15 November 2026), four models exceed 10²⁶ FLOP: GPT-6 Astra (9.4 × 10²⁶), Grok 4 (5 × 10²⁶), GPT-4.5 (3.8 × 10²⁶) and Grok 3 (3.5 × 10²⁶). All are closed. Epoch has no estimate for most closed flagships released in 2025–26.
